# Room Reset – Stufe 1

Statisches HTML-Spiel für GitHub Pages.

## GitHub Pages
1. Alle Dateien und den Ordner `assets` in ein Repository hochladen.
2. **Settings → Pages** öffnen.
3. **Deploy from a branch** wählen.
4. Branch `main`, Ordner `/ (root)` auswählen.

Das Spiel benötigt keinen Server und läuft vollständig im Browser.
